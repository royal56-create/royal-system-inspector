# Security Policy

Please report security issues privately to the repository maintainers rather than publishing exploit details in a public issue.

Royal System Inspector is intended for read-only inspection. It should not collect credentials, delete files, terminate processes or modify system configuration. Do not publish personal reports containing private host information.
