# Security and privacy

Royal System Inspector is designed for transparent, local inspection.

- It performs read-only queries and reads only files explicitly supplied to file commands.
- It does not request administrator/root privileges.
- It does not transmit information, run a background service, or collect telemetry.
- It does not modify, delete, or terminate user data or processes.
- FNV-1a is a non-cryptographic fingerprint. It is not suitable for passwords, signatures, or adversarial integrity verification.

Report suspected vulnerabilities privately to the repository owner rather than publishing exploit details in an issue.
